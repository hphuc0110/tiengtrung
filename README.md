# Đông Phương Học Quán — Khai - Dụng - Thông

Landing page React + TypeScript (Vite) cho khóa **Khai - Dụng - Thông**.

## Chạy dự án

```bash
npm install
npm run dev
```

Build production:

```bash
npm run build
npm run preview
```

## Cấu trúc component

```
src/
  App.tsx
  main.tsx
  index.css
  components/
    layout/     Header, Footer
    ui/         Button, Brand, SectionHeading, Reveal, FeatureIcon
    sections/   Hero, WhyChoose, Schedule, Workshops,
                LearningSpace, Curriculum, Roadmap, FAQ, FinalCTA
  data/         Nội dung tĩnh (FAQ, lộ trình, workshop, …)
```
